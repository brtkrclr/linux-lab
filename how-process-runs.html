Inside ./hello

Run a command in the terminal, then step through every fork, clone, execve, page fault, write and wait the kernel performs to make it happen.

Representative example, not a recording. Traces model Linux x86-64 with glibc and bash 5.2. PIDs, addresses, syscall flags and order, buffer sizes, timings and kernel function names are illustrative and vary with kernel version, libc, compiler, architecture and environment. Each step marks what is guaranteed and what varies. Run strace -f in your own container to see a real trace.
